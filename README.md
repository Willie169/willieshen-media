# directory-listing

This is a template repository that uses [github-pages-directory-listing](https://github.com/jayanta525/github-pages-directory-listing), [deploy-pages](https://github.com/actions/deploy-pages), and [delete-artifact](https://github.com/marketplace/actions/delete-artifact) to deploy GitHub page.

See <https://willie169.github.io/directory-listing> for the demo site deployed with the [directory-listing.yml](.github/workflows/directory-listing.yml) GitHub Action.

When using this template repository,
- Go to Settings > Pages > Build and deployment > Source and set to GitHub Actions.
- [data/demo.txt](data/demo.txt) is a demo file. You can delete it.
- Ensure [data](data) directory isn't empty.
